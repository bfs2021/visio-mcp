# R29 Levels Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add optional levels with default-0 semantics, consistent editing/rendering, and VSDX round-tripping.

**Architecture:** Canonical JSON Schema generates TypeScript/.NET contracts and validators. One app-level task delivers contract, transaction, clipboard, DrawScript, MCP, editor and renderer support together so no branch integration can accept a level the canvas ignores. A follow-on Visio task stores nonzero values in `AgentLevel`, retaining the existing document-schema marker.

**Tech Stack:** JSON Schema, TypeScript, Vitest, React/maxGraph, .NET 10, xUnit, native VSDX package XML.

**Spec:** `docs/design/R29-levels-contract-migration-proposal.md`

## Global Constraints

- Keep document `schemaVersion` and VSDX `AgentSchemaVersion` at 1.
- An absent `level` means 0; canonical planner writes omit level 0, and setting 0 removes the property.
- Accept explicit level 0 at ingress for compatibility; level must be an integer in `[-127, 127]`.
- Drawable leaf order is lexicographic `(level ?? 0, zIndex)`; leaf `zIndex` remains page-global and unique.
- Group level and zIndex mirror the greatest `(level, zIndex)` among descendant leaves.
- Do not change route planning or the R23 pass-through policy in issue #62.

## Review Focus

- A set-to-zero operation must produce no diff for an element whose level was already absent; repeated zero writes must not churn transaction hashes, undo, or route signatures.
- A mixed-level group move that would cross either level bound must reject atomically with no partial mutation.
- Equal-level connectors retain current zIndex hop ownership; cross-level crossings use level first, then zIndex, including large zIndex values.
- Imported file order conflicts across levels preserve AgentLevel and report `level_order_conflict`; same-level file order stays authoritative.
- Missing/invalid AgentLevel cells import safely; invalid values use level 0 with a diagnostic and do not abort the file.
