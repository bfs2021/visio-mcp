# W08 — editor image/PDF export and Copy as image

[Issue #30](https://github.com/rp2839/visio-mcp/issues/30) · [approved design](../design/W08-editor-export.md)

The File menu now exports PNG, JPEG and SVG for the current page or selection; all-page image export produces one ordered ZIP. Export PDF preserves document page order and original sizes. Edit > Copy as image publishes native bitmap and PNG formats without touching the internal object clipboard.

The editor pins document/session/revision and selected IDs. Host dialogs choose destinations, the existing export policy enforces forbidden paths and scoped overwrite consent, and an atomic writer rechecks identity/revision/destination after the temporary file is durable. Missing assets, bad geometry, rendering errors, changed revisions or destinations leave the previous file intact. Clipboard publication checks cancellation, active identity and revision on the UI dispatcher immediately before publication. Selection renders exclude unselected overlapping objects while keeping the original routed geometry.

Exact scale is explicit (pixels per point); excessive output is refused instead of silently reduced. Page background opacity/gradients, white and transparent choices use the same SVG paint for image formats. JPEG flattens onto white and rejects transparent output. Bounds: 32 pages, 8192 pixels per dimension, 16 MP per page, 64 MP total and 64 MiB encoded output. The host operation has an eight-minute lifetime; its page-side timeout is ten minutes so normal native dialog waits cannot return an early unknown outcome. Other bridge timeout behaviour is unchanged.

PDF uses a temporary host-controlled WebView2 print document with scripts, host objects, permissions, downloads, external requests and navigation blocked. It does not navigate the editor. PrintToPdfStreamAsync experimentally normalized mixed page sizes; the same installed Chromium PDF engine's Page.printToPDF API with preferCSSPageSize preserves them. A test inspects actual MediaBoxes for a landscape page and a 300 × 600 pt portrait page. Generated PDF pages were rendered and visually inspected: text and shapes are present, legible and unclipped. The installed renderer's Unicode extraction maps some punctuation to replacement characters despite correct visible glyphs; lossless PDF text extraction/accessibility is not claimed.
